# BY ARCH — Maxicon Incorporadora

Projeto de curadoria e apresentação de residências de altíssimo padrão com a assinatura dos principais escritórios de arquitetura contemporânea do Brasil.

Uma abordagem editorial e artística onde a arquitetura autoral é o diferencial central e protagonista da experiência.

---

## 🏛️ Conceito e Diferenciais

* **Arquitetura Autoral Exclusiva:** Residências desenhadas especificamente a partir da topografia, insolação e ventos de cada terreno.
* **Escritórios Renomados:** Obras assinadas por mestres como *Studio Bernardes*, *FGMF Arquitetos*, *Jacobsen Arquitetura*, *Studio MK27*, *Arthur Casas Design* e *Metro Arquitetos*.
* **Design System de Luxo:** Estética inspirada no template *VistaHaven*, com linhas limpas, cantos esculturais arredondados, microinterações e paleta suave.
* **Experiência Privada & Concierge:** Atendimento confidencial e focado em apresentação de maquetes físicas e memoriais descritivos.

## 🚀 Como Visualizar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web, ou rodar um servidor local leve:

```bash
python3 -m http.server 8080
```
E acessar: `http://localhost:8080`
